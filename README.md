# irec-kicad

This repository is for holding KiCAD electronics project files that the OSU BSLI IREC team have worked on.

An equivalent repository does not exist for Altium designs created by the team because the team is using their Altium cloud instance at https://americas-buckeye-space-launch-initiative-ohio-state-un.365.altium.com/ to store Altium project files.
